# Contributing

Issues and pull requests are welcome. Keep changes small, explain the user impact, and include verification steps.

- Do not include credentials, personal data, or private WhatsApp messages in issues, commits, or screenshots.
- Keep the Cloudflare Worker source and Termux client behavior aligned with the safety and privacy notes in both READMEs.
- The Worker may suggest shell commands but must not execute them. The Termux client must keep explicit approval before every command.
- Do not enable a second WhatsApp poller for an Agent key whose Cloudflare Cron receiver is active.
- Run the syntax checks in the README before opening a pull request.

By contributing, you agree that your contribution may be distributed under the repository's MIT license.
